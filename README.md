# Hielo y Lava Corte 20%
Videojuego 2D de plataformas cooperativo. Hielo y Lava deben llegar juntos a la meta.

## Versiones
- Motor: Unity 6000.6.6f1 LTS
- Plantilla: 2D
- Input: Input System Package (nuevo)
- Plataforma del build: Windows 64 bits

## Ejecutar el build (sin Unity)
1. Descargar HieloYLava_v0.2.zip de Releases y descomprimir completo.
2. Ejecutar HieloyLava.exe.

## Abrir el proyecto fuente
1. Instalar Unity 6000.6.6f1 con Unity Hub.
2. Hub -> Add -> Add project from disk -> carpeta del repositorio.
3. Abrir la escena Assets/Scenes/MainMenu y pulsar Play.

## Controles
| Personaje | Izquierda | Derecha | Saltar | Salir |
|---|---|---|---|---|
| Hielo (azul) | A | D | W | Esc |
| Lava (rojo) | Flecha izq. | Flecha der. | Flecha arriba | Esc |

## Datos de prueba
Al iniciar por primera vez solo el Nivel 1 está desbloqueado.
Completar el Nivel 1 (ambos personajes en la meta verde) desbloquea el Nivel 2.
Botón "Reiniciar progreso" en Selección de nivel: vuelve al estado inicial.

## Estado del alcance (corte 20%)
HU-01, HU-02, HU-03: completas. HU-05: pendiente. HU-06: avance.
